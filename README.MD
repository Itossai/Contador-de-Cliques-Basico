# Contador de Cliques Básico

Este projeto é um aplicativo simples em React que implementa um contador de cliques básico. Ele foi criado para praticar conceitos essenciais do React, como:

- Componentes funcionais
- Gestão de estado com `useState`
- Eventos de clique
- Comunicação entre componentes via importação e renderização

## O que foi feito

O projeto contém um componente chamado `Contador` que mostra quantas vezes o usuário clicou em um botão. O componente atualiza o valor em tempo real sempre que o botão é pressionado.

O `App.js` importa e renderiza o componente `Contador`, e a interface foi mantida simples para focar no funcionamento do contador.

## Requisitos para executar

Para rodar o projeto, você precisa ter instalado no seu sistema:

- Node.js (versão 14 ou superior recomendada)
- npm (vem junto com o Node.js) ou Yarn

## Como usar

1. Abra o terminal na pasta do projeto `meu-contador-react`
2. Execute:
   - `npm install`
3. Inicie o servidor de desenvolvimento:
   - `npm start`

O projeto será aberto automaticamente em `http://localhost:3000`.

## Observação

Se você criou o app diretamente na pasta atual usando `npx create-react-app .`, a pasta precisa estar vazia ou não conter arquivos que conflitariam com o React app.
